NEWXMEM – 내일 이어서 하기
==============================

1) 전부 "저장"된 상태: Git main 이 remote 와 맞음 (작업 끊기면: git status 로 확인)
   원격: https://github.com/aklexwang/NEWXMEM

2) 로컬 개발 (base = /NEWXMEM/)
   - npm run dev  →  http://localhost:5173/NEWXMEM/
   - 배포랑 똑같이 보려면:  npm run build:verify  후  npx vite preview
     →  http://localhost:4173/NEWXMEM/

3) GitHub Pages (배포)
   - https://aklexwang.github.io/NEWXMEM/
   - 푸터에 "v0.1.0" 붙이면 방금 올라간 배포(버전 in package.json, vite define)

4) 어드민 (접근 승인 관리)
   - /NEWXMEM/access-admin.html
   - 풀URL:  https://aklexwang.github.io/NEWXMEM/access-admin.html
   - 로그인 없음 (URL 직링크 = 비공개 URL 자체가 게이트, 클라이언트사이드 가짜인증은 제거)
   - 배포/캐시:  Ctrl+Shift+R  또는 시크릿

5) 자주 건드린 경로
   - src/pages/LandingPage.tsx  (랜딩, 핵심기능 ai.gif, Flow, 푸터, 버전 문구)
   - src/index.css  (.font-copyright, Pretendard는 index.html CDN)
   - public/access-admin.html, public/ai.gif, public/.nojekyll
   - vite.config.ts  (base: /NEWXMEM/, __APP_VERSION__)
   - .github/workflows/deploy.yml  (npm run build, scripts/verify-base.mjs)

6) 내일 AI에게 할 말 예시
   "D:\home\NEWXMEM 프로젝트 이어감. TOMORROW-이어하기.txt 봤어."

[ 진행중: 커스텀 도메인 (is-a.dev 무료) ]
==============================

목적
   - https://aklexwang.github.io/NEWXMEM/  → URL 에서 GitHub 사용자명(aklexwang) 가리기
   - 무료 서브도메인 .is-a.dev 사용 (개인/비상업 프로젝트만 허용)

진행 상황 체크리스트
   [x] is-a-dev/register fork 완료 → https://github.com/aklexwang/axpay
   [ ] 서브도메인 이름 결정 (사용자 보류)
       후보:  aklx / xmem / aklexwang / newxmem
       금지:  axpay  (← pay 가 들어가면 상업적이라 거절 위험 큼.
              fork 이름이 axpay 인 건 OK, 서브도메인 이름만 다르게)
   [ ] 이메일 결정 (PR owner.email, 공개 노출됨)
   [ ] 사용자가 fork 레포(aklexwang/axpay)의 domains/<이름>.json 추가
         {
           "owner":   { "username": "aklexwang", "email": "<이메일>" },
           "records": { "CNAME": "aklexwang.github.io" }
         }
       ※ CNAME 값은 레포명(NEWXMEM) 빼고 aklexwang.github.io 만!
   [ ] 본 레포(is-a-dev/register)로 PR 제출
   [ ] 머지 대기 (보통 수시간~1~2일)
   [ ] 머지 후: DNS 자동 등록 (수분~24h 전파)
   [ ] AI 가 처리할 후속작업:
        - public/CNAME 파일에 <이름>.is-a.dev 한 줄 추가
        - 커밋·푸시 → dist 에 CNAME 박힘 확인
        - GitHub Settings → Pages → Custom domain 에 <이름>.is-a.dev 입력
        - DNS check 통과 후 "Enforce HTTPS" 체크
        - (선택) vite.config.ts base 를 "/" 로 바꿔 루트 서빙
            ① 루트 옵션:  https://<이름>.is-a.dev/access-admin.html  ← 깔끔
            ② 그대로:     https://<이름>.is-a.dev/NEWXMEM/access-admin.html
   [ ] 라이브 검증

복귀 시 트리거
   사용자가 "도메인 변경" 이라고 말하면 위 체크리스트 이어서 시작.
   먼저 [서브도메인 이름] 과 [이메일] 부터 받기.
